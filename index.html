SMS Backup Converter

Turns an SMS Import / Export backup into a file that SMS Backup & Restore can restore on your new phone: texts, picture messages, group chats and all.

🔒 Works offline. Your messages never leave this device.

1 Open your backup

Choose the messages-YYYY-MM-DD.zip file that SMS Import / Export made, or the folder you unzipped it into (the one that contains messages.ndjson and data).

Drop the ZIP file or folder here

2 What's in it

    Options
    SIM card id written into each message

    Android 14 and later hide restored messages whose SIM id belongs to the old phone. "Unknown" (-1) is what Android expects for messages from another device.

    Only if your new phone's messaging app hides the restored messages; see "If the messages don't show up" below.

    Characters a backup file cannot store

    Invisible control characters (such as NUL) that XML files cannot hold. Every change is listed in the report.

    Other

    Used to rebuild group chats. Only change it if the detected number is wrong.

    Only affects the human-readable date text; the real timestamps are kept exactly.

    3 Create the backup files

    Make the small test file first and restore it on the new phone. If it looks right, make and restore the full backup; messages that are already on the phone are skipped.

    4 Restore on your new phone

    1. Install SMS Backup & Restore (by SyncTech) from Google Play and open it.
    2. In its Settings → Backup settings → Local backup folder, choose or create a folder, for example SMSBackupRestore.
    3. Copy the file you created into that folder on the phone (USB cable, a USB stick, or a cloud drive and the phone's Files app). Keep the name starting with sms-.
    4. Optional: Menu → View backups shows what's in the file without changing anything.
    5. Tap Restore, pick the file, tick Messages and start. Allow the app to be your SMS app while it restores, then switch back to your usual messaging app.
    6. Do the test file first. Check names, times, sent/received sides, photos and group chats. Then restore the full backup the same way.
    If the messages don't show up

    Wait a minute and restart the phone. If they are still missing, your phone's messaging app may want a real SIM id instead of "unknown": send one text on the new phone, make a messages backup with SMS Backup & Restore, open that file in a text editor and note the number in sub_id="…". Then come back here, choose Options → Use this id with that number, and create the files again.
